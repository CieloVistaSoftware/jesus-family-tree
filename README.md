# JesusFamilyTree

Interactive Biblical genealogy visualization focused on clarity, navigation, and historical context.

## Overview

JesusFamilyTree is a static website project generated from the createWebsite workflow and then promoted to a maintained product.

The project provides:
- Scroll and drag exploration of lineage data
- Tooltip and hover affordances for names and relationships
- Lightweight browser-first rendering with no backend dependency

## Current Status

This project is in active refinement and quality-hardening.

## Run Locally

1. Open the project folder.
2. Serve the folder with any static file server.
3. Open index.html in your browser.

Example using Node:

```bash
npx serve .
```

## Project Structure

- index.html: Main UI and rendered content
- meta.json: Project metadata
- test scripts: Regression and tooltip behavior checks
